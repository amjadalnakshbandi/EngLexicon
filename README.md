# EngLexicon

An Android application built with Kotlin that functions as a dictionary for the English language. It interacts with a free web API to search for words and retrieve their definitions, synonyms, nouns, and adjectives. The user interface is designed using XML.

## Features

- Search for any English word through a user-friendly interface.
- Retrieve detailed information including:
  - Nouns
  - Adjectives
  - Definitions
  - Synonyms
